Glosario de la Unidad

Algoritmo de Machine Learning

Conjunto de reglas o procedimientos matemáticos que permiten a un sistema aprender patrones a partir de datos y realizar predicciones o clasificaciones sin ser programado explícitamente para cada caso.

Aprendizaje automático (Machine Learning)

Subcampo de la inteligencia artificial que permite a los sistemas aprender a partir de datos históricos para identificar patrones, generar modelos predictivos y apoyar la toma de decisiones.

Clasificación

Técnica de aprendizaje supervisado que consiste en asignar una observación a una categoría o clase específica con base en las características de los datos de entrada.

Conjunto de datos de entrenamiento (Training Set)

Subconjunto de datos utilizado para entrenar un modelo de machine learning, permitiendo que el algoritmo aprenda patrones y relaciones entre variables.

Conjunto de datos de prueba (Test Set)

Conjunto de datos utilizado para evaluar el rendimiento de un modelo previamente entrenado, verificando su capacidad de generalización sobre datos nuevos.

Modelo predictivo

Representación matemática o computacional construida a partir de datos históricos que permite estimar o predecir valores futuros o comportamientos dentro de un sistema.

Overfitting (Sobreajuste)

Situación en la que un modelo se ajusta excesivamente a los datos de entrenamiento, capturando incluso el ruido o las variaciones irrelevantes, lo que reduce su capacidad para generalizar a nuevos datos.

Regresión

Técnica de aprendizaje supervisado utilizada para predecir valores numéricos continuos a partir de una o más variables independientes.

Scikit-learn

Biblioteca de Python ampliamente utilizada para implementar algoritmos de machine learning, incluyendo modelos de clasificación, regresión, clustering y herramientas de evaluación de modelos.

Validación del modelo

Proceso mediante el cual se evalúa el desempeño de un modelo de machine learning utilizando métricas y datos de prueba para determinar su precisión y capacidad de generalización.

Variable dependiente

Variable cuyo valor se desea predecir dentro de un modelo de machine learning. También se conoce como variable objetivo o variable de salida.

Variable independiente

Variable utilizada como entrada en un modelo predictivo y que influye en la estimación o predicción de la variable dependiente.
